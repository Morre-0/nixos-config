# Инструкция по быстрой установке NixOS Unstable (LUKS + Btrfs)

Эта инструкция создана для того, чтобы развернуть твою готовую и очищенную конфигурацию со всеми программами (Zen Browser, Ghostty, Pywalfox-native) на новом ПК или после форматирования диска.

## 🚀 Установка одной командой

1. Загрузись с официальной **Live-CD флешки NixOS**.
2. Подключи интернет (для Wi-Fi используй команду `nmtui`).
3. Перейди в режим суперпользователя:
   ```bash
   sudo -i
   ```
4. Запусти ультимативную команду автоматической разметки и установки (без паролей от GitHub):
   ```bash
   nix --experimental-features "nix-command flakes" run github:nix-community/disko -- --mode zap_create_mount --flake "github:Morre-0/nixos-config#nix-btw"
   ```

---

## 🛠️ Что произойдет дальше:

1. **Шифрование LUKS**: Скрипт остановится и попросит тебя дважды ввести пароль для защиты твоего диска `nvme1n1`.
2. **Авто-разметка**: Утилита `disko` сама затрёт старые таблицы, создаст разделы `nvme1n1p1` (1GB `/boot`), `nvme1n1p2` (467.1GB LUKS + Btrfs субтома) и `nvme1n1p3` (8.8GB Swap).
3. **Сборка NixOS**: Система автоматически выкачает твою конфигурацию из ветки **unstable**, поставит Zen Browser, настроит пользователя `slfhrmfn` и пропишет алиасы (включая `nix-clean`).

---

## 🔑 Финальный шаг (Задать пароль пользователя)

Как только установка завершится, перед перезагрузкой обязательно задай пароль для своего пользователя `slfhrmfn`, чтобы войти в систему:

```bash
nixos-enter --root /mnt -c "passwd slfhrmfn"
```
*(Введи новый пароль два раза).*

После этого смело пиши:
```bash
reboot
```
Вытаскивай флешку. При старте ПК вводи пароль шифрования диска и наслаждайся своей идеальной системой!
