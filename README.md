# 🚀 Инструкция по быстрой установке NixOS Unstable (LUKS + Btrfs)

Эта инструкция создана для того, чтобы в любой момент развернуть твою идеальную модульную конфигурацию со всем софтом (**Zen Browser**, **Ghostty**, **Pywalfox-native**) на новом ПК или после форматирования диска.

## 💾 Установка одной командой

1. Загрузись с официальной **Live-CD флешки NixOS**.
2. Подключи интернет (для беспроводной сети используй команду `nmtui`).
3. Перейди в режим суперпользователя:
   ```bash
   sudo -i
   ```
4. Запусти автоматическую разметку и установку (без паролей от GitHub):
   ```bash
   nix --experimental-features "nix-command flakes" run github:nix-community/disko -- --mode zap_create_mount --flake "github:Morre-0/nixos-config#nix-btw"
   ```

---

## 🛠️ Что сделает Disko автоматически:

1. **Шифрование LUKS**: Скрипт остановится и попросит тебя дважды ввести секретный пароль для защиты твоего диска `nvme1n1`.
2. **Геометрия разделов**: Утилита сама затрёт старые таблицы и нарежет структуру:
   * `nvme1n1p1` — Загрузочный раздел **EFI** (1 Гигабайт в формате vfat).
   * `nvme1n1p2` — Зашифрованный контейнер **LUKS** (467.1 Гигабайт) с субтомами **Btrfs** (`/`, `/home`, `/nix`).
   * `nvme1n1p3` — Раздел подкачки **Swap** (8.8 Гигабайт).
3. **Сборка системы**: Выкачает чистый модульный код из твоего репозитория, накатит ветку **unstable**, настроит автологин в Hyprland и добавит алиас глубокой очистки `nix-clean`.

---

## 🔑 Финальный шаг (Пароль пользователя)

Как только сборка пакетов завершится, перед перезагрузкой обязательно задай пароль для своего пользователя `slfhrmfn`, чтобы успешно войти в систему:

```bash
nixos-enter --root /mnt -c "passwd slfhrmfn"
```
*(Введи новый пароль два раза).*

После этого смело отправляй компьютер в перезагрузку:
```bash
reboot
```
Вытаскивай флешку, вводи пароль шифрования диска при старте и наслаждайся своей ультимативной сборкой!
