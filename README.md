# 🚀 Ультимативная модульная сборка NixOS Unstable (LUKS + Btrfs)

Добро пожаловать в эталонную, минималистичную и полностью структурированную конфигурацию NixOS. Система переведена на передовую ветку разработки **Unstable**, избавлена от тяжелого окружения GNOME и настроена на моментальный автоматический вход в **Hyprland** через правильную сессию `dbus-run-session` под твой Lua-конфиг.

---

## 📂 Чистая структура репозитория

Корень системы избавлен от монолитного кода и находится в идеальном порядке:
* 📁 `disk/` — Декларативная разметка **Disko** (LUKS + Btrfs + Swap).
* 📁 `user/` — Настройки Home Manager (`home.nix`), профили **Zen Browser** и **Pywalfox-native**.
* 📁 `user/dotfiles/` — Твои личные конфигурации программ (включая **Hyprland на Lua**), которые декларативно разворачиваются в `~/.config/`.
* 📁 `modules/` — Изолированные системные подмодули:
  * ⚙️ `core/boot.nix` — Загрузчик `systemd-boot`.
  * ⚙️ `core/nix-settings.nix` — Флейк-функции, утилита `fastfetch`, базовый CLI-софт и кастомные алиасы `nix-upgrade` / `nix-clean`.
  * 🌐 `network/default.nix` — Хостнейм `nix-btw`, NetworkManager, безопасность Git и unfree-пакеты.
  * 🌍 `system/locale.nix` — Локализация (RU) и часовой пояс (Москва).
  * 👥 `system/users.nix` — Профиль пользователя `slfhrmfn` и его группы.
  * 🔊 `system/sound.nix` — Звуковой сервер `Pipewire` + подсистема реального времени `rtkit`.
  * 📡 `system/bluetooth.nix` — Bluetooth с автозапуском и графический трей `Blueman`.
  * 💻 `desktop.nix` — Настройка автоматического входа `greetd` в графическую сессию DBus.
  * 🛠️ `desktop/hyprland-apps.nix` — Нативная экосистема Wayland-утилит (**Waybar**, **Rofi-Wayland**, **Swww**, **Dunst**, **Thunar**).

## ⚡ Установка на новый ПК одной командой

Чтобы развернуть этот точный слепок системы на новом компьютере (с диском `nvme1n1`), тебе понадобится только официальная установочная флешка NixOS и интернет.

### Шаг 1: Подготовка и запуск
1. Загрузись с официальной **Live-CD флешки NixOS** в режиме UEFI.
2. Подключи интернет (для Wi-Fi введи команду `nmtui`).
3. Перейди в режим суперпользователя:
   ```bash
   sudo -i
   ```
4. Запусти автоматическую разметку, шифрование диска и установку (пароли от GitHub не требуются):
   ```bash
   nix --experimental-features "nix-command flakes" run github:nix-community/disko -- --mode zap_create_mount --flake "github:Morre-0/nixos-config#nix-btw"
   ```

---

## 🛠️ Что сделает установщик автоматически:

1. **Запросит пароль LUKS**: Скрипт остановится и попросит тебя дважды ввести секретный ключ для полной зашифровки накопителя.
2. **Разметит геометрию**: Создаст разделы `nvme1n1p1` (1GB `/boot`), зашифрованный `nvme1n1p2` (467.1GB с Btrfs-субтомами под `/`, `/home`, `/nix` со сжатием `zstd`) и `nvme1n1p3` (8.8GB Swap).
3. **Накатит систему и дотфайлы**: Скачает пакеты из ветки **unstable**, применит все модули, установит **Zen Browser**, **Ghostty** и **Thunar**, а Home Manager автоматически развернет твои Lua-конфиги из папки `dotfiles/` прямо в `~/.config/` нового ПК.

---

## 🔑 Финальный шаг перед перезагрузкой

Как только сборка пакетов полностью завершится, **обязательно задай пароль** для своего пользователя, иначе система заблокирует вход:

```bash
nixos-enter --root /mnt -c "passwd slfhrmfn"
```
*(Введи новый пароль два раза).*

После этого завершай установку:
```bash
reboot
```
Вытаскивай флешку, вводи пароль шифрования диска при старте и наслаждайся своей идеальной системой!
