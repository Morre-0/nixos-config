# 🚀 Декларативная сборка NixOS Unstable — Tecno Megabook T1 Edition

Добро пожаловать в эталонную, минималистичную и полностью структурированную конфигурацию NixOS. Система переведена на передовую ветку разработки **Unstable**, работает на самом свежем **Mainline-ядре Linux** со встроенными аппаратными патчами для ноутбука **Tecno Megabook T1** и разворачивает монолитную, плавную графическую среду **GNOME Workstation** на базе **Wayland** (в стиле Fedora).

---

## 📂 Чистая модульная структура репозитория

Корень системы избавлен от монолитного кода и находится в идеальном порядке:
* 📁 `disk/` — Декларативная разметка дисков **Disko** (LUKS + Btrfs + Swap).
* 📁 `user/` — Настройки пользователя через Home Manager (`home.nix`), профили софта (**Zen Browser**, **Pywalfox-native**).
* 📁 `modules/` — Изолированные системные подмодули:
  * ⚙️ `core/boot.nix` — Загрузчик `systemd-boot` + принудительное переключение на последнее **Mainline-ядро Linux**.
  * ⚙️ `core/nix-settings.nix` — Экспериментальные флейк-функции, утилита `fastfetch` (`fetch`), базовый CLI-софт и кастомные алиасы.
  * 🌐 `network/default.nix` — Хостнейм `nix-btw`, NetworkManager, правила безопасности Git и unfree-пакеты.
  * 🌍 `system/locale.nix` — Русская локализация (RU) и часовой пояс (Москва).
  * 👥 `system/users.nix` — Профиль пользователя `slfhrmfn` и его системные группы.
  * 🔊 `system/sound.nix` — Звуковой сервер `Pipewire` + подсистема реального времени `rtkit`.
  * 📡 `system/bluetooth.nix` — Bluetooth с автозапуском и графический трей `Blueman`.
  * 🌍 `system/fonts.nix` — Кэш шрифтов (включая **JetBrainsMono Nerd Font** и **Comic Sans MS**).
  * 💻 `system/hardware-tecno.nix` — **Аппаратные патчи для Megabook T1 (T15DA)**:
    * Фикс встроенного микрофона Realtek ALC269 (принудительный DMAC ACPI).
    * Настройка глубокого сна Deep Sleep (S3) без перегрева процессора.
    * Драйвер `amd_pstate` для дикого энергосбережения AMD Ryzen.
    * Включение **Triple Buffering** и оптимизации `amdgpu` для 100% плавности анимаций GNOME.
  * 💻 `desktop/gnome.nix` — Чистый графический стек GNOME Workstation, экран входа GDM на Wayland, нативный терминал `gnome-console` и `gnome-tweaks`.

## ⚡ Установка на новый ПК одной командой

Чтобы развернуть этот точный слепок системы на новом компьютере или ноутбуке (с диском `nvme1n1`), тебе понадобится только официальная установочная флешка NixOS и интернет.

### Шаг 1: Подготовка и запуск
1. Загрузись с официальной **Live-CD флешки NixOS** в режиме UEFI.
2. Подключи интернет (для беспроводной сети введи команду `nmtui`).
3. Перейди в режим суперпользователя:
   ```bash
   sudo -i
   ```
4. Запусти ультимативную команду автоматической разметки, шифрования диска и установки:
   ```bash
   nix --experimental-features "nix-command flakes" run github:nix-community/disko -- --mode zap_create_mount --flake "github:Morre-0/nixos-config#nix-btw"
   ```

---

## 🛠️ Что сделает установщик автоматически:

1. **Запросит пароль LUKS**: Скрипт остановится и попросит тебя дважды ввести секретный ключ для полной зашифровки твоего NVMe накопителя.
2. **Разметит геометрию**: Создаст разделы `nvme1n1p1` (1GB `/boot`), зашифрованный `nvme1n1p2` (467.1GB с Btrfs-субтомами под `/`, `/home`, `/nix` со сжатием `zstd`) и `nvme1n1p3` (8.8GB Swap).
3. **Накатит систему и дотфайлы**: Скачает свежие пакеты ветки **unstable**, применит все патчи ядра для Tecno, установит **GNOME**, **Zen Browser**, а Home Manager настроит профиль пользователя без твоего ручного вмешательства.

---

## 🔑 Финальный шаг перед перезагрузкой

Как только сборка пакетов полностью завершится, **обязательно задай пароль** для своего пользователя внутри установленной системы, иначе она заблокирует вход:

```bash
nixos-enter --root /mnt -c "passwd slfhrmfn"
```
*(Введи новый пароль два раза).*

После этого завершай установку:
```bash
reboot
```
Вытаскивай флешку, вводи пароль шифрования диска при старте и наслаждайся своей идеальной системой!
