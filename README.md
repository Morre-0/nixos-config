# 🚀 Ультимативное руководство по установке NixOS Unstable (LUKS + Btrfs)

Добро пожаловать в твою эталонную, минималистичную и модульную конфигурацию NixOS. Этот репозиторий настроен на передовую ветку **Unstable**, использует автоматический вход в **Hyprland** (через правильный `start-hyprland`), содержит предустановленный **Zen Browser**, **Pywalfox-native** и ультимативный алиас очистки диска **`nix-clean`**.

Вся геометрия дисков декларативно описана через **Disko**. Данное руководство позволит развернуть эту систему с нуля на любом компьютере с диском `nvme1n1`.

---

## 📁 Структура твоего репозитория

* 📁 `disk/` — Декларативная разметка **Disko** (LUKS + Btrfs + Swap).
* 📁 `user/` — Конфигурация **Home Manager** (`home.nix`), пользовательский софт и плагины.
* 📁 `modules/` — Разделённые системные подмодули:
  * ⚙️ `core/boot.nix` — Настройки загрузчика `systemd-boot`.
  * ⚙️ `core/nix-settings.nix` — Флейк-функции, CLI-софт (`nvim`, `git`, `curl`), кастомный алиас `nix-clean`.
  * 🌐 `network/default.nix` — Хостнейм `nix-btw`, NetworkManager, безопасность Git и unfree-пакеты.
  * 🌍 `system/locale.nix` — Русская локализация и часовой пояс (Москва).
  * 👥 `system/users.nix` — Профиль твоего пользователя `slfhrmfn`.
  * 🔊 `system/sound.nix` — Звуковой сервер `Pipewire` + `rtkit`.
  * 📡 `system/bluetooth.nix` — Bluetooth с автозапуском и графический менеджер `Blueman`.
  * 💻 `desktop.nix` — Графический стек `Hyprland` и правильный автологин `greetd`.

## 🛠️ ПОШАГОВАЯ ИНСТРУКЦИЯ ПО УСТАНОВКЕ (ОТ И ДО)

### Шаг 1: Подготовка загрузочной флешки
1. Скачай самый свежий ISO-образ NixOS (рекомендуется графический x86_64 образ с GNOME или Plasma, так как в нём проще запустить терминал и Wi-Fi).
2. Запиши образ на флешку через программу **Rufus** (в режиме DD), **BalenaEtcher** или команду `dd` в Linux:
   ```bash
   sudo dd if=nixos.iso of=/dev/sdX bs=4M status=progress && sync
   ```

### Шаг 2: Загрузка в Live-CD и настройка сети
1. Вставь флешку в новый ПК, зайди в Boot Menu материнской платы и выбери загрузку в режиме **UEFI**.
2. Открой терминал внутри Live-системы.
3. Подключи интернет:
   * Если подключён интернет-кабель (Ethernet) — сеть подхватится автоматически.
   * Если используешь Wi-Fi, введи команду:
     ```bash
     nmtui
     ```
     Выбери свою точку доступа, введи пароль и убедись, что сеть активна (проверь через `ping google.com`).

### Шаг 3: Переход в режим суперпользователя
В консоли Live-CD перейди под учётную запись root:
```bash
sudo -i
```

### Шаг 4: Запуск автоматической разметки и установки
Выполни одну ультимативную команду (ввод паролей или токенов от GitHub не требуется, так как репозиторий открытый):
```bash
nix --experimental-features "nix-command flakes" run github:nix-community/disko -- --mode zap_create_mount --flake "github:Morre-0/nixos-config#nix-btw"
```

#### Что произойдет в процессе выполнения команды:
1. **Шифрование LUKS**: Скрипт остановится и попросит тебя:
   `Enter passphrase for /dev/nvme1n1:`
   Придумай и введи надёжный пароль (дважды). Этот пароль будет защищать твой компьютер, его нужно будет вводить при каждом включении ПК.
2. **Авто-разметка**: Утилита `disko` сама затрёт старые разделы и создаст новые:
   * `nvme1n1p1` — Системный загрузчик **EFI** (1GB, vfat, путь `/boot`).
   * `nvme1n1p2` — Зашифрованный слой **LUKS**, внутри которого развернётся файловая система **Btrfs** с субтомами для `@root` (`/`), `@home` (`/home`), `@nix` (`/nix`) и прозрачным сжатием `zstd`.
   * `nvme1n1p3` — Раздел подкачки **Swap** (8.8GB).
3. **Сборка пакетов**: Начнётся автоматическая утилита `nixos-install`. Она скачает твой модульный код с GitHub, подтянет ветку **unstable**, скомпилирует ядро, установит Zen Browser, Ghostty и настроит автологин.

### Шаг 5: Создание пароля пользователя (КРИТИЧЕСКИ ВАЖНО)
Когда сборка пакетов полностью завершится и на экране появится финальная строка ввода, тебе нужно обязательно задать пароль для входа твоего пользователя `slfhrmfn`. Если этого не сделать, система заблокирует вход.

Выполни команду проброса в установленную систему:
```bash
nixos-enter --root /mnt -c "passwd slfhrmfn"
```
*Терминал попросит тебя ввести новый пароль для пользователя `slfhrmfn` два раза. Вводи его внимательно (символы при вводе отображаться не будут).*

### Шаг 6: Финал и Перезагрузка
Всё готово! Выходи из режима установки и отправляй компьютер в перезагрузку:
```bash
reboot
```
Вытаскивай установочную флешку из разъёма.

## 🏁 Что ты увидишь после перезагрузки:

1. При старте ПК появится текстовый экран с просьбой расшифровать диск. Введи свой пароль от **LUKS**, созданный на Шаге 4.
2. Система мгновенно расшифрует разделы Btrfs, автоматически пролетит экран TTY (благодаря `greetd` и `start-hyprland`) и сразу откроет твой полноценный, рабочий, красивый графический стол Hyprland.
3. Твой терминал будет снабжён алиасом **`nix-clean`** для ухода за диском, а в системе будут развёрнуты Zen Browser и Pywalfox-native!
